# DUO ARENA · MISSIONS

Локальный 3D-шутер на Three.js для двух и более игроков в одной Wi-Fi сети: PvP-дуэль на двоих или кооперативное выживание против зомби с 10 миссиями, боссом, ловушками, вооружёнными зомби и пиротехникой.

## Возможности

- **Дуэль**: раунд до 7 побед, вид сверху, автоприцел.
- **Зомби-режим**: 10 разных миссий (доставка груза, запуск генератора, оборона реактора, эвакуация), подключение новых игроков на ходу (до 64 мест).
- **Босс**: броня, шкала натиска (оглушение при заполнении), круговой удар с замахом, таранная атака по линии.
- **Зомби**: обычные, быстрые, танки, крикуны (призывают подкрепление), хвататели (утаскивают игрока), ~30% вооружены дальней атакой с предупреждающей линией.
- **Опасности карты**: мины (50 урона, есть время уйти) и движущиеся механизмы, которые окончательно выводят игрока из матча.
- **Интерактивные узлы миссий**: добавочные механизмы, активируемые E / «Действие».
- **Пиротехника**: взрывы мин, вспышки выстрелов, искры ловушек, салют на эвакуации.
- **Мобильное управление**: джойстик, кнопки огня/рывка/действия/перезарядки.

## Установка

```bash
npm install
npm start
```

Сервер выведет адреса localhost и LAN. Авторитативная логика в server.mjs, клиент Three.js в index.html.
